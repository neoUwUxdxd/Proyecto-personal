¿Tu llave abre la puerta?

Pega una API key, elige el proveedor y comprueba al instante si funciona, qué modelos desbloquea y cómo responde. La petición va directa de tu navegador al proveedor: aquí no se guarda nada.

Estás dentro de Claude. Aquí las páginas no pueden conectarse a otros servidores, así que Llavero prepara los comandos para que pruebes tu llave desde la terminal. Para probarla con un clic, abre llavero.html directamente en tu navegador. En la pestaña Chat puedes hablar con Claude.

Qué significa cada color

El resultado sale de la respuesta HTTP del proveedor.

  • Válida. El proveedor la aceptó y listó sus modelos.
  • Limitada. Existe, pero sin saldo o con demasiadas peticiones (402 / 429).
  • Rechazada. Llave incorrecta, revocada o sin permisos (401 / 403).
  • Sin conexión. Red caída o el proveedor no admite llamadas desde webs (CORS).
